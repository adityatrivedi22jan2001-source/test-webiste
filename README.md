# Renaissance Edition website clone

This is a working HTML/CSS/JS recreation based on the supplied 74-second reference video.

## Run
Open `index.html` in a modern browser.

For best results, run a local server:
- VS Code + Live Server, or
- `python -m http.server`

## Included
- `index.html` — page structure
- `style.css` — layout, typography, responsive styling
- `script.js` — section navigation/active chapter behavior
- `assets/reference.mp4` — the supplied video used as the cinematic hero reference

## Important
The video does not expose the original site's source code, fonts, image assets, or exact animation timings. This build reproduces the visible composition, navigation, typography direction, section hierarchy and interaction pattern as closely as possible from the supplied reference. For a true pixel-for-pixel clone, the original assets/source or higher-resolution references are required.
